POSTGRESQL 17 - DATABASE IMPORT INSTRUCTIONS
===============================================

FOLDER STRUCTURE

schema/
  init.sql
  seq.sql
  indexes.sql

data/
  admin.sql
  location.sql
  supplier.sql
  address.sql
  client.sql
  repair.sql
  vehicle.sql
  buying.sql
  ticket.sql
  demand.sql
  repairInfo.sql
  subscription.sql

IMPORTANT:
Use the corrected versions of:
- supplier.sql
- repair.sql
- vehicle.sql
- buying.sql

Do NOT mix the old files with the corrected files.


================================================
1. CREATE THE DATABASE
================================================

Open PostgreSQL 17 with psql:

psql -U postgres

Create the database:
For example
CREATE DATABASE car_rental;

Connect to it:
For example
\c car_rental


================================================
2. EXECUTE init.sql FIRST
================================================

Run:

\i 'C:/path/to/schema/init.sql'

Replace the path with the real path on your computer.

init.sql must be executed FIRST because it creates:
- tables
- ENUM types
- constraints
- foreign keys


================================================

================================================

Run these commands one by one:

\i 'C:/path/to/data/admin.sql'

\i 'C:/path/to/data/location.sql'

\i 'C:/path/to/data/supplier.sql'

\i 'C:/path/to/data/address.sql'

After ALL data has been inserted:

================================================
8. VERIFY FOREIGN KEYS
================================================

Every query below should return ZERO rows.

-- Suppliers without a valid admin
SELECT s.*
FROM suppliers s
LEFT JOIN admins a ON a.id_admin = s.id_admin
WHERE a.id_admin IS NULL;

-- Clients without a valid admin
SELECT c.*
FROM clients c
LEFT JOIN admins a ON a.id_admin = c.id_admin
WHERE a.id_admin IS NULL;

-- Clients without a valid location
SELECT c.*
FROM clients c
LEFT JOIN locations l ON l.id_location = c.id_location
WHERE l.id_location IS NULL;

-- Vehicles without a valid supplier
SELECT v.*
FROM vehicles v
LEFT JOIN suppliers s ON s.id_supplier = v.id_supplier
WHERE s.id_supplier IS NULL;

-- Buyings without a valid client
SELECT b.*
FROM buyings b
LEFT JOIN clients c ON c.id_client = b.id_client
WHERE c.id_client IS NULL;

-- Buyings without a valid vehicle
SELECT b.*
FROM buyings b
LEFT JOIN vehicles v ON v.id_vehicle = b.id_vehicle
WHERE v.id_vehicle IS NULL;

-- Tickets without a valid client
SELECT t.*
FROM tickets t
LEFT JOIN clients c ON c.id_client = t.id_client
WHERE c.id_client IS NULL;

-- Tickets without a valid repair center
SELECT t.*
FROM tickets t
LEFT JOIN repairs r ON r.id_repair = t.id_repair
WHERE r.id_repair IS NULL;

-- Tickets without a valid vehicle
SELECT t.*
FROM tickets t
LEFT JOIN vehicles v ON v.id_vehicle = t.id_vehicle
WHERE v.id_vehicle IS NULL;

12. COMMON ERRORS
================================================

ERROR: relation does not exist

Cause:
init.sql was not executed first.

Solution:
Execute init.sql before the data files.


ERROR: column does not exist

Cause:
You are probably using an OLD SQL file.

Make sure you use the corrected:

supplier.sql
repair.sql
vehicle.sql
buying.sql


ERROR: violates foreign key constraint

Cause:
A referenced entity was not inserted before the current entity.

Solution:
Follow the exact execution order in this file.


ERROR: invalid input value for enum

For vehicles, valid statuses are:

AVAILABLE
TAKEN
REPARATION

NOT:

RENTED
REPAIR


For buyings, the column is:

id_vehicle

NOT:

id_vehicule
